# LittleNet Pipeline Map

Baseline: `f48aafa1bce0fb1344dfc8aec57f70770d8dfc0b`, 2026-09-15. Initial source map; transitive database/worker tracing remains explicitly unverified until each bounded domain is released. This is a reference map, not a progress tracker. See ASTRA_RELEASE_LEDGER.md.

## Required end-to-end paths

```text
Parent register → Resend OTP → verify email → ACTIVE → Android device auth (biometric/PIN) gates Parent Mode → dashboard
Parent → create child → required age quiz → Kids
Kids login → password → authoritative quiz gate → destination
Session restore → secure token → /me → authoritative role/gates → navigation → bounded Kids prefetch
Kids hydration → home/stories + Feed page 1 + Reels page 1 + Explore + profile + notifications
Feed/Reels/Explore/search → eligibility before ranking → authorized media → actions/signals → refresh
Image/video → upload session → private quarantine PUT → completion validation → durable job → Modal moderation
ALLOW → sanitize/promote → publish → invalidate profile/Home/Feed/Explore/Search/Reels
REVIEW → private authorized Parent/Admin review → audited approve/block/escalate
BLOCK → cleanup/invalidate → never public
Chat → approved relationship + controls → paginated text/shared-post send/read → moderation → unread refresh
Parent controls → persisted limits/categories/features → child request gate → screen-time/quiet-hours denial
R2 delivery → viewer authorization → signed delivery/proxy → private bytes
Network error → explain/retry → preserve only safe checked capture → reconnect → revalidate server state
Database writes → existing connection/transaction layer → commit or rollback → authoritative response
```
