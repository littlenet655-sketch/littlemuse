# Text-only moderation dependencies.
#
# Why this file exists: parent/routes.py's create_child flow calls
# safety.text_service.check_text() on registration metadata (child name,
# school, class, location, bio) before allowing account creation. That
# currently pulls in the *entire* requirements-ai.txt stack transitively
# (nudenet, ultralytics/YOLO, faster-whisper, deepface, tensorflow) even
# though none of those models are used for text. That couples basic parent
# onboarding to a multi-GB install and several unrelated model downloads
# that have nothing to do with checking a name field.
#
# Install this alone (on top of requirements-core.txt) for any deployment
# that needs working text moderation without needing to install the full
# vision/audio pipeline yet:
#
#   pip install -r requirements-core.txt -r requirements-text.txt
#
